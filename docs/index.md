# streamgrab

A small Chrome extension that saves the video or audio playing on the current page: direct media files, and HLS and
DASH streams copied into an MP4 without re-encoding. No accounts, no limits, no telemetry, and no server of its own.

- [Privacy policy](privacy.md)
- [README: features, install and how it works](https://github.com/xingfanxia/streamgrab#readme)
- [Source code](https://github.com/xingfanxia/streamgrab) (MIT)

The Chrome Web Store version does not save from YouTube and does not circumvent DRM. Only save media you have the
right to keep.
